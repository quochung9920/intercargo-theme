# 4.6.2 — Unlimited Sections

All top-level section packages are repeatable. The framework enforces `supports.multiple = true` for every `sectionPackage`, including future LLM-generated sections.

Hero participates in the same shared-section workflow as Services.

Runtime section IDs preserve the first historical anchor and suffix later instances to avoid duplicate IDs (`services`, `services-2`, `services-3`, ...).
