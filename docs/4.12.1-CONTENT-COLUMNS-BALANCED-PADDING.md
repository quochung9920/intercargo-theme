# 4.12.1 — Content Columns balanced padding hotfix

## Root cause

4.11.4 introduced adjacency selectors that split `--section-y` between two consecutive service Content Columns. That reduced the bottom padding of the first section and the top padding of the second, so the content was no longer vertically centred inside either background band.

The Air Freight source does not collapse adjacent section padding. It uses a symmetric rule on every section:

```css
.air-section {
  padding-block: var(--af-section-y);
}
```

The theme already provides the equivalent shared primitive:

```css
.section-pad {
  padding-block: var(--section-y);
}
```

## Fix

- Removed the frontend adjacency `:has()` spacing rules.
- Removed the Gutenberg-only adjacency mirror rules.
- Kept the 4.11.5 legacy `section-head-gap` cleanup.
- Paper and White variants now differ only by surface/divider treatment; both retain identical symmetric top/bottom section padding.
- Runtime contract now rejects any reintroduction of the half-padding adjacency hack.

No global spacing token was changed.
