# 4.8.0 — Service Hero

## Authority order

1. **Current theme 4.7.2.1** is authoritative for global layout primitives: `.container`, `--page-gutter`, fonts, colours, header state, reusable form infrastructure and section package conventions.
2. The supplied **Air Freight static build** is authoritative for Service Hero composition and hero-specific responsive geometry.
3. Service-specific content is editable Gutenberg content. Do not fork the block into Air/Sea/Customs/Land variants.

## Container and spacing

Service Hero uses the existing global `.container` directly for both the breadcrumb alignment and the overlapping card. It does not define a second content width, max-width or page-gutter formula.

The Air Freight source explicitly corrected a previous `1184px` capped hero card because it stopped growing on wide screens. The current theme's `.container` already implements the corrected rule: viewport width minus two global page gutters, with no hard max-width. 4.8.0 keeps that behaviour.

Hero-only measurements use section-scoped custom properties copied from the verified 390px/1440px source anchors. They do not leak into `:root`.

The two-column hero split remains **1100px**, not the site's usual 960px breakpoint. This is intentional source behaviour: the compact form column needs enough room to avoid squeezing the lead copy and growing the card unexpectedly.

## Shared placeholder media

`assets/placeholders/media-placeholder.webp` is the canonical neutral placeholder for new image-based sections when no real artwork is available yet.

- 32 × 32 solid neutral WebP
- no content-specific text or branding
- intended to scale via `object-fit: cover`
- single shared file instead of duplicated placeholder assets per section
- replace through native Gutenberg Media Replace when real artwork is ready

Existing approved sections are not rewritten to the placeholder during this release. The asset is a reusable default for new/original section templates and future image-based packages.

## Editing model

- Background/media: native Gutenberg Replace Media control
- Breadcrumb: inline RichText paragraph, including inline link editing
- H1: inline heading
- Lead: inline paragraph
- Form prompt and response note: inline paragraphs
- Form provider/form selection: existing provider-neutral Form infrastructure, surfaced by the Service Hero section inspector
- Shared variants: existing `Reuse & sync` workflow

## Out of scope

- `air-secnav`
- service-specific page templates or duplicated service hero blocks
- changes to existing Home Hero geometry
- global container/token redesign

## QA evidence

Static Chromium geometry checks use the real 4.7.2.1 global CSS plus the new Service Hero stylesheet and self-hosted theme fonts.

- 390px: hero 565px, media 230px, card top 134px, global container gutter ~20px
- 1440px: hero 444px, media 300px, card top 182px, card/container width 1184px with 128px theme gutters
- 1100px: two-column split activates exactly at the verified source breakpoint
- 320–2560px: 113-width sweep, zero horizontal overflow and zero card/next-section overlap
- Air Freight and Sea Freight content variants both remain structurally safe; longer copy grows the normal-flow card/section rather than clipping

At 390px the global `.container` retains the theme's existing subpixel `--page-gutter` interpolation. This is intentionally not locally corrected: global theme alignment has priority over creating a separate Service Hero container calculation.
