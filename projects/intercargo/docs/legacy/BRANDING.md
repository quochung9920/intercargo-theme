# Branding and header variants (4.7.1)

Customizer → Intercargo Brand provides two independent logo slots:

- **Primary logo (white header)** — used when the page uses the default light header.
- **White logo (transparent header)** — used on transparent/dark headers, the mobile menu and footer.

The historical single `intercargo_logo` theme mod is migrated to the White logo slot once so existing homepages keep their approved branding.

Header dropdowns also follow the page header variant:

- Light/white header → white dropdown surface, dark text.
- Transparent header → existing dark dropdown surface, light text.
