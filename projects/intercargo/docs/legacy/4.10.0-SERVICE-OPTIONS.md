# 4.10.0 — Service Options

## Purpose

Port the Air Freight “Which air service you need.” panel as a service-family-neutral Gutenberg section.

## Data model

`Service Options` owns the section heading and introduction. Each `Service Option` owns one destination and the following editable fields: service title, service description, condition label and condition text. Rows are an open Gutenberg collection and may be duplicated, removed, reordered or added.

## Shared-theme priority

The section uses the existing global `.container`, `section-pad`, colour tokens and font families. Only panel-specific measurements from the Air Freight source are scoped to the section.

## Service Navigation

Because the block is a normal top-level `sectionPackage`, Service Navigation discovers it automatically. No navigation-specific copy or target is duplicated in this package.

## QA

- Original Air Freight panel vs 4.10.0 at 1440/1920/2560: container width, heading geometry, panel position/width, row height, responsive columns and condition width match exactly apart from browser subpixel rounding.
- At 390/768/960 the internal panel geometry remains matched; only the outer vertical section padding follows the existing theme `section-pad` token by design, because shared-theme spacing has priority over the standalone Air Freight prototype.
- Stress sweep: 320–2560 px in 20 px steps with eight deliberately long rows produced zero horizontal page overflow and zero row escape from the panel.
