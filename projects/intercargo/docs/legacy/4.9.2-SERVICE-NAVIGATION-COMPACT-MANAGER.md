# 4.9.2 — Compact Service Navigation Manager

The Service Navigation remains fully page-derived. Version 4.9.2 only simplifies its editor UI.

## Inspector row

Each discovered section is represented by one compact row only:

```text
⋮⋮  [ Editable tab title ]  ☑
```

- Drag `⋮⋮` to change navigation order without moving page sections.
- Edit the title directly in the row. The value is stored on the source section as `serviceNavTitle`.
- Untick the checkbox to exclude the section from Service Navigation.
- There is no separate **Tab title** field.
- There is no **Target ID** field in the Service Navigation manager.

## Automatic targets

Targets are resolved from the actual section renderer. The existing section anchor contract remains the single source of truth, and repeated anchors are automatically uniquified (`services`, `services-2`, `services-3`, ...). The navigation manager does not maintain or expose a second target value.

If a section already has an explicit section anchor from its own section settings, Service Navigation follows that rendered ID automatically.

## Data ownership

Service Navigation owns only `tabOrder` and its CTA settings. Title override and visibility stay on the source section. It remains `syncable: false` and `reusable: false`.
